# CleanTube

Reklamsız, tamamen yerel (Jetpack Compose) bir YouTube istemcisi.

- Oynatma: [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor) (GPLv3) + Media3. Reklam verisi hiç alınmaz.
- Hesap: Google girişi yalnızca oturum çerezini almak için kullanılır; çerez cihazda Android Keystore ile şifreli saklanır, sadece youtube.com'a gönderilir.
- Güvenlik: tek izin INTERNET, HTTPS zorunlu, yedekleme kapalı, uygulama debuggable değil.

APK: **Releases > latest > CleanTube.apk**

Lisans: GPLv3 (NewPipeExtractor ile uyumlu).
